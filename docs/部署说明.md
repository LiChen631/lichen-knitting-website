# 部署说明

## 一、本地预览

```bash
# Windows 下双击
lichen_knitting_website\preview-local.bat

# 或者用任意静态服务器
cd lichen_knitting_website
python -m http.server 8000
```

打开 <http://127.0.0.1:8000/index.html>，英文版加 `?lang=en`。

## 二、修改内容

| 想改什么 | 改哪里 | 注意 |
| --- | --- | --- |
| 页面文字 | 对应 `.html` 里的 `data-zh` / `data-en` | 中英文两份都要改 |
| 电话 / 微信 / 地址 | 改 `tools/gen_site.py` 里的常量后重新生成 | 9 个页面都出现，手改容易漏 |
| 工厂照片 | 覆盖 `assets/img/factory-*.jpg` | 保持 16:9、≤ 300 KB |
| 面料图 | 覆盖 `assets/img/fabric-*.jpg` | 保持 4:3、≤ 200 KB |
| 视频 | 覆盖 `assets/video/*.mp4` | **必须 H.264 编码**，HEVC 浏览器播不了 |
| 整体结构 / SEO | 改 `tools/gen_site.py` 后 `python tools/gen_site.py` | 会覆盖所有 HTML |

改完建议先自检：

```bash
python tools/check_site.py
```

## 三、部署到 Cloudflare Workers（当前使用方式）

本站以「静态资源 Worker」形式托管，没有服务端代码。

首次部署（需要 Cloudflare 账号并完成邮箱验证）：

```bash
npm install -g wrangler
wrangler login                      # 浏览器授权
wrangler deploy                     # 在含 wrangler.toml 的目录执行
```

`wrangler.toml` 关键配置：

```toml
name = "www"
compatibility_date = "2026-10-01"

[assets]
directory = "../../lichen_knitting_website"
not_found_handling = "404-page"
html_handling = "auto-trailing-slash"
```

后续更新：改完文件重新执行 `wrangler deploy` 即可，只有变化的文件会被上传。

> 部署凭据保存在执行部署那台电脑的本地配置中（`wrangler` 的 OAuth 凭据），
> **不要复制给他人、不要提交到仓库**。网站本身是纯静态前端，访客可查看源码，
> 因此仓库中不得存放任何密钥、令牌或后台凭据。

## 四、绑定自有域名

1. 在 Cloudflare 中把域名指向该 Worker（Workers → 你的 Worker → Settings → Domains & Routes）
2. 更新仓库里的站点地址，并重新生成 SEO 元信息：

```bash
python tools/set_domain.py https://your-domain.com
python tools/gen_site.py
wrangler deploy
```

这会更新所有页面的 `canonical`、`og:url`，并重新生成 `sitemap.xml` 与 `robots.txt` 中的 Sitemap 声明。

> 想撤销回到「未设置域名」状态：`python tools/set_domain.py --clear`

## 五、上线后的检查清单

- [ ] 首页、各子页面、404 页面均可正常访问
- [ ] HTTPS 生效（地址栏为锁形图标）
- [ ] 手机端显示正常，顶部导航可展开
- [ ] 中英文切换正常，切换后标题与描述同步变化
- [ ] 电话 `tel:` 链接可拨号，微信可复制
- [ ] 高德地图链接可打开且定位正确
- [ ] 视频可播放（H.264）
- [ ] `sitemap.xml` 可访问，并已提交到搜索引擎站长平台

## 六、可选：提交搜索引擎

- [Google Search Console](https://search.google.com/search-console)：提交 `sitemap.xml`
- [Bing Webmaster Tools](https://www.bing.com/webmasters)：同上
- 百度搜索资源平台：需先绑定自有域名

## 七、后续若需要在线询价

当前询价表单**不会发送也不会保存**任何数据，只用于整理文本供复制。
如果需要客户在线提交并保存询价记录，需要另外实现：

1. 表单接收接口（Cloudflare Workers / 任意后端）
2. 数据存储（D1、数据库或表格服务）
3. 垃圾提交防护（校验、验证码、频率限制）
4. 隐私告知与数据保留策略

不要用纯静态页面假装能保存客户数据。
