## 4. 更换素材时的注意事项

1. **版权**：只使用自有素材、已获授权素材或 CC0 / 公共领域素材。使用 CC BY / CC BY-SA
   素材时必须在页面上保留署名，并说明授权条款。
2. **不要用他人厂房照片冒充本厂**：这类图片会被客户识破，也可能涉及虚假宣传。
3. **视频格式**：请使用 H.264 编码的 MP4（H.265/HEVC 在多数浏览器无法播放）。
4. **体积**：卡片图建议 ≤ 200 KB，宽图 ≤ 300 KB，视频 ≤ 1 MB，否则手机访问较慢。
5. **更新 `alt` 文字**：换了图片一定要同步改 HTML 里的 `alt`，这关系到无障碍访问和搜索收录。
